# Source picker native request ownership

The additional whole-project Astra pass reproduced a separate source-picker hang: its two-second structured task-group timeout still awaited a screenshot continuation that might never resume. Repeated refreshes created more untracked preview tasks. The independently extracted original code produced three outstanding requests and zero finished waits after the real deadline; all waits returned only after synthetic callbacks were released (`/private/tmp/muesli-thumbnail-proof/result.log`). No actual screen was captured for that test.

`NativeCallbackOwner` now admits one native callback operation and invokes it away from the interface. Both the method's actual return and its first callback are required before the slot is reusable. Duplicate callbacks are ignored under the original operation identity. `TaskCompletion` bounds each wait independently; timeout/cancellation retains the original native owner and does not create replacement work. Native failure frees the slot only after actual invocation return.

Picker refreshes refuse overlapping content loads, cancel and retire the preceding preview generation immediately, and snapshot the current display/window list. Every thumbnail publication checks that generation and cancellation after its await. Unresolved native thumbnail ownership ends the batch with a visible unavailable message; disappearance of an individual window may skip that preview normally. Native screenshot requests ask for 160×90 pixels directly, with fit scaling, instead of converting and resizing full-display buffers on the interface actor. The bounded callback helper also owns shareable-content enumeration, shared by permission probes and picker refreshes. A timeout or busy request is no longer treated as proof of revoked screen permission; the current system preflight supplies that state.

Apple's supported image callback API is documented at [captureImage(contentFilter:configuration:completionHandler:)](https://developer.apple.com/documentation/screencapturekit/scscreenshotmanager/captureimage%28contentfilter%3Aconfiguration%3Acompletionhandler%3A%29). Actual macOS SDK compilation verifies its use here.

Six synthetic native-owner regressions cover first/duplicate results, missing callback and refusal of another invocation, callback-before-blocked-return plus an interface heartbeat, cancellation retaining ownership, old duplicate callbacks during a new request, and native failure. Production picker integration and source membership are included in the application build. No hardware, permission change, source capture, client data or installed app is used in these tests.
