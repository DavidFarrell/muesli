# Read-only recorded-source eligibility

`ArchiveSourceEligibility.inspect(access:)` is a synchronous file-worker operation. The caller supplies an already retained **exclusive** `MeetingFileAccess`; the result retains that access, all secondary leases, and the exhaustive `ArchiveSourceInventory` snapshot. This helper never recovers a journal, creates a missing lock, starts a process, changes source files, moves a meeting, or enables cleanup UI. It is not safe to call on MainActor. A future bounded owner must retain the original worker through actual completion after its waiter times out; this helper does not provide that async owner.

Before reading source bytes, a bounded descriptor-relative topology pass discovers every capture, artifact, event-journal, backend and transaction lease, including those inside unindexed folders. Existing-only nonblocking exclusive acquisition refuses an active owner. Indexed current sources require their capture lock and actual `transcript_events.jsonl` lock, artifact sources require their artifact lock, and the meeting requires its backend lock. Missing required ownership evidence is a legacy/unknown refusal, never an invitation to create it. Regular, single-link, current-user file checks and retained parent/child identities prevent alias substitution. The topology must still equal the subsequent exhaustive inventory; source/lease identities and the exact unresolved-transaction path are rechecked before return. No `TranscriptPersistenceStore.Context` or automatic recovery path is used.

Every indexed session must have a distinct positive numeric ID, distinct valid source UUID, the current indexed audio folder, a known completed outcome, and a finite contiguous source extent. Its current PCM manifest must identify the same UUID and offset, have a real committed revision/date, and explicitly contain exactly mic and system at 16 kHz mono. Actual PCM length must equal its even committed byte count; captured frames must equal committed frames. All loss records, omitted details, gaps, overlap, drops, problems and optional recorded power interruptions must be absent. Completed metadata alone is insufficient. `initial_source_alignment` explicitly refuses automatic archive as **recorded alignment requiring review**; it does not assert that hardware lost speech. Legacy WAV-only or unknown-duration sources remain retained.

Each stream's exact owned PCM is streamed again to bind a derived canonical 44-byte-header WAV fingerprint, even if no compatibility WAV exists. A present compatibility WAV must exactly match that fingerprint. `Session` exposes the inventoried PCM records, actual manifest record/revision/offset and `modelInputs` byte counts/hashes; the latter have no path because they do not assert that a physical WAV exists. These immutable inputs are for the separate future processing-evidence verifier and are not evidence that a model ran.

For sessions that requested video/screenshots, the indexed modern artifact ledger must have the correct source/offset header, a single matching `capture_stopped`, unique source-scoped screenshot/video UUIDs, and an actual requested-to-finished pair for every video. Every indexed file must exist, finished video sizes must equal SDK-recorded byte extents, times/durations must be finite, and metadata counts/closure/extents must agree. Empty/torn/pending/failed/unknown records and unindexed files or directories (including empty directories) refuse. Terminal SDK events may arrive after `capture_stopped`; that does not lose their provenance. This establishes **recorded SDK completion plus inventoried files**, not independent PNG/MP4 decoding or first-frame video alignment. Audio-only sessions legitimately have no artifact store and must instead have an exact PCM-backed duration.

Modern manual attachments require unique immutable UUID filenames, a known indexed source/time, and matching actual byte count/hash. Legacy or missing provenance remains retained. Root transcript/log/evidence files stay in the complete source hash inventory but cannot establish capture closure, speech absence, processing coverage, speaker identity, redaction or approval. Any unaccounted descendant directory or file, and root-level unindexed media, refuses.

Limits: metadata and attachment indexes 4 MiB each, PCM manifests 1 MiB each, asset ledgers 16 MiB per session, 64 KiB per ledger record, 100,000 ledger records total, 1,024 sessions, 10,000 manual attachments and **64 MiB combined semantic reads across all sessions**. Ledger parsing walks lines without first allocating an unbounded slice array. JSON duplicate keys (including escaped aliases) and excessive nesting/nodes refuse before typed decoding. Topology and streamed byte hashing retain the inventory foundation's 100,000-entry/32-level/16-MiB-path/64-GiB-file/256-GiB-total limits; secondary ownership has a 4,096-lease bound. Lower OS descriptor limits can cause a truthful refusal. Per-stream PCM is limited to 24 hours and hashing uses fixed 64 KiB buffers.

Synthetic tests exercise normal audio-only and two-session artifact capture, actual `LocalAudioRecorder` WAV output, absent derived WAVs, every loss class, interrupted power evidence, malformed/duplicate records, incorrect source offsets, missing/tail PCM, missing assets, unindexed empty directories, modern/legacy attachments, actual kernel lease contention and retention, topology/root/ancestor replacement, changed semantic bytes, aggregate limits and unresolved journal preservation. An actual inspection worker is deliberately stalled while MainActor's wait expires; the original leases remain held until the worker returns and its retained result is released. No hardware, model download, client recording, real Trash or external skill is used.

A future archive owner still must retain these owners through fresh receipt/input/output revalidation and any actual move, prove per-source/per-stream processing coverage and byte-edit evidence, and persist a recoverable pending outcome outside the source. Advisory leases establish cooperation only for the qualified participating app/backend boundary. They do not prove that an arbitrary older or uncooperative process has stopped. The external Merge closed-app gate remains unchanged.
