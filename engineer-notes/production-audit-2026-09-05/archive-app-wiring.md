# Native archive application wiring

The application now constructs one process-lifetime `ArchiveApplicationBridge` after configuring cooperative Quit. Construction itself has no filesystem/socket work. Enabling dispatches bootstrap and listener construction onto the original retained lifecycle worker. Existing Muesli support directories keep their permissions; only fixed ArchiveBridge, ArchiveOperations and ArchiveJournal children are created as private 0700 directories through retained no-follow descriptors. A missing ancestor, wrong owner, symlink or nonprivate existing child causes explicit listener failure without chmod or replacement.

The bridge owns one semantic workflow across listener generations. New begin/finalize work uses atomic open-only shutdown admission; native-context retirement uses the separate accepted-successor admission factory. Accepted Quit closes semantic/listener admission synchronously before quiescence. Cancel Quit can reopen the same owner and request one successor listener after original closure, but cannot restore a retired proof. The UI shows listener startup/readiness/failure/closure and offers an explicit retry after startup failure.

Backend selection is supplied only by the native AppModel selection/bookmark path through a synchronized value box. Each accepted preparation captures an immutable adapter with that selected root and the fixed native output/journal roots; later backend selection changes cannot replace an existing operation's adapter. The local command cannot supply an executable, backend root, mover, callback or serialized processing proof. Source/vault paths and the exact native-manifest receipt destination remain the protocol's external inputs. The semantic adapter alone invokes the fixed processing and private staged-source Trash operations.

This source change activates the listener when this build of the application is launched. Qualification did not launch or replace the installed app, create real user support roots, start a recording, invoke real Finder Trash, or modify the external Merge skill. Participating installed-build verification and the remaining release/hardware gates are separate. The initial semantic adapter still requires its independently identified prelaunch original-source admission correction before this combined implementation can be integrated as approved.

Local combined validation passed 70 actual tests: two concrete bridge/socket/Quit tests, five native-root tests, fourteen semantic adapter tests, twenty-three workflow tests, twelve listener lifecycle tests and fourteen cooperative Quit tests.
