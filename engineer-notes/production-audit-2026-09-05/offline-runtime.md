# Offline runtime policy

Recording and reprocessing use local assets. Package initialization sets the Hub offline policy before model imports, disables telemetry, and rejects Python DNS and IP socket operations. Local Unix IPC remains available to MLX/CoreML. ASR resolves both configuration and weights from one existing local directory/cache revision using `local_files_only=True`; it never falls back to downloading. FFmpeg receives a local input protocol allowlist, including for media that references other resources.

The app forces the recording/reprocessing environment into this policy, overriding an inherited provisioning override. The separate standalone `scripts/prepare-local-models.py --allow-download --revision <exact upstream commit>` command is an explicit online preparation step and does not read meeting data. After validating and hashing the downloaded snapshot it atomically publishes `local-models.json` beside the backend project. Both app and reprocessing use that pinned selection automatically; a missing or invalid selected directory fails closed instead of silently selecting another cached revision. Existing installations without a selection retain their local-cache compatibility lookup. Runtime missing-asset errors retain source audio and report inference unavailable.

`python -m diarise_transcribe.local_assets --diarisation --hashes` verifies required local assets, including nonempty native libraries, the pinned Senko CoreML payload layout and both clustering configurations and produces file hashes for release provenance without loading a model. The current Mac passes the presence preflight for ASR and the Senko native/CoreML assets. Presence does not prove successful model initialization or inference; those require the separate offline runtime qualification.

The Python network guard and dependency settings are not an operating-system sandbox for arbitrary native extensions. An enforceable whole-process no-network release claim still requires the signed helper's OS policy and a disconnected acceptance run. This document does not certify that gate. App Sandbox network permissions also cover localhost, so an Ollama integration must remain a separately described boundary rather than silently granting inference unrestricted networking.

References: [Hub offline environment policy](https://huggingface.co/docs/huggingface_hub/en/package_reference/environment_variables), [Apple outgoing network entitlement](https://developer.apple.com/documentation/bundleresources/entitlements/com.apple.security.network.client), [Apple sandbox inheritance](https://developer.apple.com/library/archive/documentation/Miscellaneous/Reference/EntitlementKeyReference/Chapters/EnablingAppSandbox.html).
